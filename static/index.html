ONE-TIME SETUP

A little setup.
Then a lot of quiet.

Install Ollama from ollama.com on the same machine as the Still server. Then run:

ollama pull qwen2.5:1.5b
ollama serve

Already running Ollama? You can skip the second command. Refresh the connection when the download finishes.

The first model download needs internet. After that, generation can run offline. This hosted preview cannot reach Ollama on your laptop; run Still locally for private generation.
